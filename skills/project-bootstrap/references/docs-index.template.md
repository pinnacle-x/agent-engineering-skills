# Optional Project Document Index

This reference is only for projects **already using an index** or sufficiently complex projects where one is genuinely helpful. Grill/Wayfinder have their own documentation and local tracker pointers. Do **not** create an additional `docs/README.md` automatically or duplicate issue/spec/ADR contents.

When maintaining an existing index, link actual source-of-truth paths only, with applicability and current status.

| Resource | Actual path / link | Status and applicability |
| --- | --- | --- |
| Current system architecture | <real path, if it exists> | Current implemented facts / confirmed target distinctions |
| High-level design | <real path, if it exists> | Current; relevant modules |
| Approved requirements | <real path, if it exists> | Confirmed |
| Technical constraints | <real path, if it exists> | Verified current / accepted target |
| Domain guidance | <configured domain guidance path> | Read glossary / ADRs by scope |
| Local tracker | <configured tracker guidance path> | Locate relevant Map and task spec |
| Historical designs | <real historical path> | Superseded; not current implementation instructions |

An index is a **map, not a parallel specification**. Do not invent paths; keep existing file locations and do not mirror every new ticket in `AGENTS.md`.
